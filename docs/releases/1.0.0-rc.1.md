# SecondLook 1.0.0-rc.1

**Prerelease candidate — not a fully validated production v1.0 release.**

## What is included

- Local, explainable message and URL checks; URLs are inspected without opening them.
- Personal blocklist and local cache refreshed from the FTC Do Not Call reported-calls daily CSV.
- Optional Android call screening through Android’s user-selected system role.
- Optional on-device scan history, display themes, and local settings.
- User-initiated `text/plain` share-to-analysis flow.

## Requirements and installation

- Android 8.0 (API 26) or newer.
- Package: `com.developercal.secondlook`; versionCode 2.
- Download `SecondLook-1.0.0-rc.1.apk` from this GitHub Release. Verify its SHA-256 checksum before installing, then open the APK and follow Android’s installer prompts.
- The app’s README and [screenshots](https://github.com/TheDeveloperCal/SecondLook-Android/tree/main/docs/screenshots) document the tested UI and installation.

## Limitations

- Native call screening is not active until the user selects SecondLook as Android’s call-screening app. The BLU test device currently reports no role holder.
- No real incoming carrier call or TextNow call was observed; call-screening behavior on an eligible physical call is not verified.
- Select SecondLook through Android’s official call-screening role prompt before expecting native calls to be screened.
- The TextNow-origin share path was not tested. Synthetic Android `ACTION_SEND` prefill and no-automatic-analysis behavior passed.
- FTC records are unverified consumer reports, not confirmed scam findings. They never automatically block calls, and caller ID can be spoofed.
- Message rules are English-focused; link checks are structural only and do not query live website reputation.
